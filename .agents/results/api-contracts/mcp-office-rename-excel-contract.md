# MCP Office Rename And Excel Contract

> Generated by PM Agent | Session: mcp-office-rename-excel-20260630 | Date: 2026-06-30

## Transport
`stdio` MCP servers shipped by `@pro-select/pros-cli`.

## Authentication
- Local DOCX, PowerPoint, and Excel file MCPs require no provider credentials.
- Microsoft Graph requires delegated OAuth token material in the OS Credential Store only.
- No tool may expose secrets, raw tokens, or unrestricted local filesystem access.

## Server Names

| Capability | New Server Name | Command | Notes |
|---|---|---|---|
| Microsoft Graph | `microsoft-graph` | `mcp-microsoft-graph` | Remove Pros-specific naming from the command while preserving credential target semantics separately if needed. |
| DOCX local files | `docx-local` | `mcp-docx-local` | Workspace-guarded local DOCX inspection, extraction, and preview planning. |
| PowerPoint local files | `powerpoint-local` | `mcp-powerpoint-local` | Renamed from office-files because implementation is PPTX-only. |
| Excel local files | `excel-local` | `mcp-excel-local` | New workspace-guarded local XLSX/XLSM-denying Excel server with approved write support. |

### `excel-local`

| Tool | Input | Output | Side Effects |
|---|---|---|---|
| `xlsx_inspect` | `{ path }` | workbook metadata, sheet names, dimensions, table/range summary | None |
| `xlsx_extract` | `{ path, worksheet?, range?, format? }` | Markdown table and/or JSON cell matrix | None |
| `xlsx_read_range` | `{ path, worksheet, range }` | bounded A1 range values with sheet/range metadata | None |
| `xlsx_plan_edit` | `{ path, edits[] }` | workbook edit preview with affected sheets/ranges | None |
| `xlsx_apply_approved_edit` | `{ path, previewId, confirmationStatus: "CONFIRMED" }` | updated file path and backup path | Writes only after explicit confirmation |

## Safety Rules
- All local file paths must pass the existing workspace guard.
- Macro-enabled files (`.xlsm`) are denied for write operations; initial V1 should prefer `.xlsx` only.
- `xlsx_apply_approved_edit` must create a backup before writing and must refuse stale or mismatched preview IDs.
- MCP write tools require explicit confirmation and must never infer approval from a prior preview.
- Tool responses must be bounded to avoid dumping entire large workbooks into MCP context.

## Documentation And Manifest Contract
- Rename every user-facing `Pros Office Files MCP` reference to `PowerPoint MCP` or `PowerPoint Local MCP`.
- Remove the `pros-` prefix from DOCX, Microsoft Graph, and PowerPoint MCP server command names and docs.
- Add Excel Local MCP to runtime manifest, CLI help, MCP command docs, and end-user docs.
- Preserve clear distinction between local Excel MCP and Microsoft Graph Excel range reads.
