# Pros Global MCP Runtime API Contract

Status: Updated 2026-07-14 after QA VERIFY remediation.

## Authoritative Scope

- `pros init` may create or maintain a local `.serena/project.yml` as workspace/developer configuration.
- `pros mcp configure` must not read, write, install, sync, repair, or manage Serena in global OpenCode or AnythingLLM client configuration.
- Existing non-Pros Serena entries are foreign client entries and must be preserved unchanged.

## Pros-managed global MCP targets

- OpenCode: `docx-local`, `excel-local`, and `powerpoint-local` are valid global Pros-managed Office includes.
- OpenCode Office entries must use `cwd: "."` and `--workspace-mode client-context`.
- AnythingLLM: Office includes (`docx-local`, `excel-local`, `powerpoint-local`) are unsupported because AnythingLLM cannot provide the validated active-workspace contract.
- AnythingLLM Office include attempts must return/report `unsupported_client_capability` and leave the config file unchanged.

## Prohibited global client config output

- No Pros-managed Serena entries.
- No `--project-from-cwd` generated by `pros mcp configure`.
- No fixed case-folder paths, `$PWD`, provider secrets, tokens, or Serena-derived paths in Pros-managed global client config.
